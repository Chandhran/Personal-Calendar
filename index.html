GitHub sync

Your schedule is stored as a JSON file in a repo you control. Create a personal access token (Settings → Developer settings → Fine-grained tokens) with read/write access to that one repo's contents.

Working hours for a date

Overrides the default 9AM–9PM window for one specific date. The rescheduler treats this as a hard boundary for that date.
